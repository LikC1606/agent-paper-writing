# 真实客户端行为结果

截至 2026-11-15，已用合成 toy 论文逐项运行 P01–P13，并独立审查工具轨迹、源码、结果来源及最终页面。Claude 各项首轮为 **8 项通过、4 项失败、1 项未验证**。P09 补充绘图源后的独立重测、辅助续跑，以及 Codex 的 P11 测试均另列，不能替换首轮结果。

这些是少量、范围明确的案例观察。写作与工程规则共同安装；重测期间有规则、材料、提示和预算变化。结果不能用于估计稳定通过率、比较模型优劣，或归因于某条规则。场景与判据见 [测试说明](testing.md) 和 [P01–P13 合同](../tests/fixtures/requirements.json)。

执行状态、条目判据和视觉质量分别判断。正常退出只表示完成执行；预算退出即使条目判据满足，整体仍为未验证。术语或构建流程条目通过，也可能同时保留失败的视觉检查。自填检查表、生成 PNG 和独立检查者查看页面，都不能单独证明被测客户端实际看过图片。

## Codex 的 P11 单项测试

补充 P11 规则后，在全新项目中运行了一次 Codex P11 测试，未沿用 Claude 的修改稿，也不是辅助续跑。执行正常完成，约 338.4 秒；四项有界内容与历史保护判据均通过。独立核对：摘要由 18 词减为 15 词，正文由 91 词减为 65 词，总计由 109 词减为 80 词，减少 26.6%；三个正文小节合为一个，摘要首次使用即定义 score threshold filter，原有数字、限制和 5 个保护文件均保留。

该次有真实新构建、单页 PDF 和客户端自行登记的视觉通过。保存的 43 行 CLI JSONL 没有图片查看工具事件，因此**被测 Codex 是否实际查看最终页面仍未验证**。独立检查者查看页面和客户端自述不能填补这个证据缺口。结论仅为 P11 内容与历史保护通过，不扩展为全局 P12 遵循，也不据此比较两个客户端的整体能力。

后续复测继续使用新目录，独立保存初始状态、执行结果与逐项评审；已有失败和未验证记录不被成功续跑覆盖。
